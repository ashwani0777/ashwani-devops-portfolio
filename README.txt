PREVIEW LOCALLY
Open index.html in a modern browser.

PUBLISH WITH GITHUB PAGES
1. Create a new public GitHub repository, for example: ashwani-devops-portfolio
2. Upload index.html, style.css, script.js and README.txt to the repository root.
3. Open repository Settings > Pages.
4. Under Build and deployment, select Deploy from a branch.
5. Select branch main and folder /(root), then Save.
6. Wait for GitHub Pages to publish the site. The URL will look like:
   https://YOUR-GITHUB-USERNAME.github.io/ashwani-devops-portfolio/

BEFORE PUBLISHING
- Confirm the phone number and email are correct.
- Add your GitHub profile/repositories if you want them displayed.
- Add real project repositories and architecture screenshots when ready.
- The contact form opens the visitor's email application; it does not store or transmit form data to a server.
- No backend or paid hosting is required for GitHub Pages.
